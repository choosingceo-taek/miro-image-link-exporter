# RACK 상품 수집기 (크롬·엣지 확장)

> **상품 리서치(미로 없이)** — 팝업 맨 위 **🔎 상품 리서치 열기**를 누르면 브랜드·상품 검색과
> 엑셀 추출 화면이 새 탭으로 열립니다. **옆 패널로 열기**를 누르면 보고 있는 페이지 옆에 붙어 열립니다.
> 화면은 인터넷 주소(`https://choosingceo-taek.github.io/miro-image-link-exporter/app.html`)에 있어
> 고쳐져도 확장을 다시 받을 필요가 없습니다. 크롬·엣지 모두 같습니다
> (옆 패널은 크롬 116 이상·최신 엣지에서만 보이고, 없으면 새 탭 버튼만 남습니다).

브랜드/카테고리 **URL 목록**을 넣으면, 확장이 각 페이지를 **백그라운드 탭으로 자동 방문**해
스크롤·수집한 뒤 **RACK 공유 저장소(미로 앱)** 로 전송합니다. 실제 크롬 탭이라 **Akamai 등 봇 차단을
자연히 통과**합니다. (Zara·Massimo Dutti·H&M·Gap 등)

> 서버가 아니라 **본인 크롬**에서 돌기 때문에 무료이며, 크롬만 켜져 있으면 됩니다.
> 완전 무인(서버 자동)은 유료 헤드리스 브라우저가 필요합니다.

## 설치 (팀원 각자, 최초 1회)
1. 이 폴더(`chrome-extension`)를 내려받습니다. (저장소에서 이 폴더만 zip으로 받아 풀어도 됨)
2. 크롬 주소창에 `chrome://extensions` 입력 (마이크로소프트 엣지는 `edge://extensions`)
3. 우상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드** → 이 `chrome-extension` 폴더 선택
5. 툴바에 **RACK 수집기** 아이콘이 생김. (Worker 주소·토큰은 기본 내장 — 설정 불필요)

> **엣지에서 쓸 때** — 코드 수정 없이 그대로 동작합니다(같은 크로미움 엔진).
> 엣지는 메뉴 이름이 **압축 풀린 확장 로드**이고, 개발자 모드 스위치가 왼쪽 아래에 있습니다.
> 엣지의 **절전 탭**(설정 → 시스템 및 성능)이 수집 탭을 재우면 수집이 비거나 느려질 수 있으니 끄거나 예외에 넣으세요.
> 크롬과 엣지 **둘 다 설치하지 마세요** — 새벽 예약이 양쪽에서 돌아 같은 브랜드를 두 번 수집합니다.

## 사용
1. 아이콘 클릭 → 팝업 열기
2. **브랜드/카테고리 URL**을 한 줄에 하나씩 붙여넣기 (각 사이트의 **상품 목록 페이지** 주소)
   - 예: `https://www.zara.com/kr/ko/woman-new-in-l1180.html`
3. **수집 시작** → 확장이 URL을 하나씩 백그라운드 탭으로 열어 자동 수집·전송, 진행률·로그 표시
4. 끝나면 미로 앱 **Market Research → 저장된 카탈로그** 칩에 자동으로 뜸 (팀 전체 공유)
   - 리서치 화면(**🔎 상품 리서치 열기**)에서도 바로 보입니다. **지금 이 페이지 수집**이 끝나면
     뜨는 **수집한 브랜드 리서치에서 보기**를 누르면 그 브랜드가 곧장 열립니다.

## 상품 리서치 화면
- 왼쪽(좁은 화면에서는 **☰ 브랜드**)에서 브랜드를 고르거나, 위 검색창에 **상품명**을 넣어 전체 브랜드에서 찾습니다(`/` 키로 바로 검색).
- **YWMN · WMN · Active · Sleep** 칩으로 브랜드를 좁힙니다(한 번 더 누르면 전체).
- 고른 상품은 브랜드를 옮기거나 검색해도 남습니다 — 여러 브랜드를 **한 엑셀**에 담을 수 있습니다.
- 혼용률 열은 고른 상품의 95% 이상에 혼용률이 있을 때만 붙습니다. 모자라면 **혼용률 있는 것만**을 누르세요.
- 주소 끝의 `#site=<브랜드 키>` · `#q=<검색어>` 로 그 화면을 바로 열 수 있습니다(즐겨찾기·공유용).

## 참고
- 한 번에 여러 개 넣으면 사이트 부담·차단 방지를 위해 **하나씩 텀을 두고** 처리합니다(개당 수 초~십수 초).
- "상품 못 찾음"이 뜨면: 그 URL이 상품 목록이 아니거나(상세 페이지 등), 사이트 구조가 특이한 경우입니다.
  그 URL을 알려주시면 수집 로직을 보강합니다.
- Worker 주소/토큰을 바꾸려면 팝업 하단 **⚙ Worker 설정**에서 변경. 바꾼 값은 리서치 화면에도 넘어갑니다.
- 리서치 화면이 옆 패널에서 안 뜨면(회사망이 GitHub Pages 를 막는 등) 패널에 이유와 **새 탭에서 열기**가 표시됩니다.
