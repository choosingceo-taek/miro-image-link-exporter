# 변경 이력

버전은 `chrome://extensions` 카드에 표시됩니다. 여기 적힌 것보다 낮으면 최신이 아닙니다.

## 1.6.1 (2026-08-02)
1.6.0 배포 뒤 수집기를 두 번 더 고쳤습니다. **1.6.0 사용자도 갱신하세요.**

- **작은 이미지 오판 수정** — 지연 로딩 중인 저해상도 상품 사진을 "아이콘"으로 보고
  버리던 문제. Carhartt sweatpants 에서 상품 66개가 이렇게 통째로 날아갔습니다.
  이제 화면에 그려진 크기로 판단합니다. (지연 로딩 40개 재현 테스트: 0개 → 40개)
- **탈락 사유 집계** — 상품이 0개일 때 어느 조건에서 걸렸는지(noImage/tinyImage/
  samePage 등) 세어서 남깁니다. 원인을 추측하지 않고 숫자로 좁힙니다.
- 플레이스홀더 이미지 제외, srcset 후보를 페이지 기준으로 해석.

## 1.6.0 (2026-08-01)
수집 정확도를 크게 고친 판. **1.5.0 사용자는 반드시 갱신하세요.**

- **느린 상품 그리드 대기** — 스크롤 후 1.5초만 기다리고 끝내던 것을 3.5초로 늘리고,
  그리드가 뜰 때까지 먼저 기다립니다. 이것 때문에 Massimo Dutti 5개·Oysho 19개·
  Lands End 17개만 저장됐습니다. (지연 페이지 재현 테스트: 0개 → 96개)
- **허브 페이지 자동 추적** — 카테고리 URL이 상품 목록이 아니라 하위 카테고리 타일만
  보여 주는 경우(FP Movement `/workout-tops/`), 타일을 최대 4개까지 따라 들어갑니다.
- **카테고리 타일·브레드크럼·로고 제외** — "Click to shop", "Discover Now" 같은 배너가
  상품으로 저장되던 문제. `Logo Tee` 같은 진짜 상품은 그대로 남습니다.
- **서비스워커 유지** — MV3가 30초 만에 워커를 종료해 수집이 중간에 조용히 멈추던 문제.
- **출처 기록(src)** — 상품마다 어느 카테고리 URL에서 왔는지 저장해 문제 추적이 가능합니다.
- 수집 시간이 30~45분으로 늘어납니다(상품을 다 받기 위한 대가).

## 1.5.0 (2026-08-01)
- **브랜드 단위 저장** — URL 하나당 저장하던 것을 브랜드 단위로 바꿨습니다.
  `shop.lululemon.com` 이 브랜드 "shop" 으로 저장되고, 같은 도메인을 쓰는
  Free People / FP Movement 가 서로 덮어써 섞이던 문제를 고쳤습니다.
- 저장 키를 야간 자동 수집과 같은 `<호스트>.<브랜드슬러그>` 로 통일.
- 매번 통째 교체(`replace`)로 어제 품절 상품이 쌓이지 않음.
- 예전 호스트 전용 키 자동 삭제.
