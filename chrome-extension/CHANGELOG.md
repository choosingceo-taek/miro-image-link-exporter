# 변경 이력

버전은 `chrome://extensions`(엣지는 `edge://extensions`) 카드에 표시됩니다. 여기 적힌 것보다 낮으면 최신이 아닙니다.

  설명 문단 · 디테일 글머리표(핏·기장·넥라인·여밈·주머니·관리법 등) · 상품 사진 전부 · 이 상품의 컬러 전부 ·

  겉감 줄이 조각이면 장식 줄로 대신하지 않고 비워 둡니다. 같은 섬유가 둘로 적히면 더하고("70% … Viscose, 30% … Viscose"),

  "100% Cotton Shop" 같은 메뉴·기획전 이름(Z Supply)과 "Modal spinner … 100% Cotton" 의 창 이름(The Great)도 소재로 읽지 않습니다.
