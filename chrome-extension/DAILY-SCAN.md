전체 134개 브랜드 중 **104개는 사람 손 없이** 매일 새벽에 자동 수집됩니다.
봇 차단(403·봇체크) 때문에 데이터센터에서는 브라우저를 써도 막히는
**30개 브랜드**만 이 확장이 담당합니다. 수집 담당 PC **1대**가 하루 한 번
실행하면, 팀원들은 아무 설정 없이 미로 앱에서 최신 상품을 봅니다.

| 구분 | 브랜드 수 | 방법 | PC 필요? |

| 서버 자동 | 85 | 매일 03:00 · GitHub Actions → Render | ❌ |

확장은 실행할 때마다 서버에서 목록을 받아오므로 브랜드가 바뀌어도 재설치가 필요 없습니다.

> 2026-08-01 전 브랜드를 헤드리스 크롬으로 실측해 분류했습니다. 데이터센터 IP에서

## 1. 수집 담당 PC 1대 정하기
- 아침에 출근해 크롬을 켜는 PC면 충분합니다. (전원이 항상 켜져 있을 필요 없음)
- 이 PC **한 대만** 설정하면 됩니다 — 결과는 팀 전체가 공유합니다.

## 2. 확장 설치(또는 업데이트) — **v1.6.0 필수**
1. 저장소 ZIP을 받아 압축 풀기
2. 크롬 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드** → 압축 푼 폴더 **안의 `chrome-extension` 폴더**를 선택
   - ⚠️ 저장소 최상위 폴더(`miro-image-link-exporter-main`)를 고르면
     "매니페스트 파일이 없습니다" 오류가 납니다. 반드시 그 안의 `chrome-extension` 을 선택하세요.
   - 이미 설치돼 있다면: 새 ZIP으로 폴더를 덮어쓴 뒤 카드의 **새로고침(↻)** 클릭
   - 카드에 **버전 1.6.0** 이 보이는지 꼭 확인하세요(확장 팝업 아래에도 표시됩니다).
     그보다 낮으면 최신이 아닙니다 — 변경 내용은 `CHANGELOG.md` 참고.
     1.5.0 은 느린 상품 그리드에서 몇 개만 수집하고 끝나며, 1.4.x 는 같은 도메인의
     두 브랜드(Free People / FP Movement)가 서로 덮어써 상품이 섞입니다.

## 3. 자동 수집 켜기
1. 크롬 오른쪽 위 확장 아이콘(RACK 상품 수집기) 클릭
2. **매일 자동 수집** 섹션에서
   - **켜기** 체크
   - **시각 입력**: 원하는 시각을 분 단위로 자유롭게 지정 (예: `08:30`)
   - **전용 창을 열어 수집** 은 켠 상태 유지(권장 — 숨은 탭은 크롬이 타이머를 늦춰 수집률이 떨어집니다)
3. **지금 전체 실행**을 한 번 눌러 정상 동작 확인
   - `30개 브랜드 · 138개 카테고리 수집 시작` 이 뜨고, 별도 창이 열렸다 자동으로 닫힙니다.
   - 카테고리마다 여러 페이지를 넘기고, 상품이 다 뜰 때까지 기다리므로 **50~70분** 걸립니다.
     게이지의 남은 시간을 참고하세요.
   - 완료 후 팝업에 `지난 실행 … — 브랜드 성공 N/30 (카테고리 138개)` 가 표시되면 정상.

## 4. 매일 아침엔 이렇게 동작합니다
- **크롬이 켜져 있으면** → 예약 시각에 자동 실행
- **크롬이 꺼져 있었으면** → 그날 처음 크롬을 켤 때 자동으로 따라잡아 실행
- 즉, 출근해서 **크롬만 켜면** 그날 수집은 자동으로 끝납니다.

## 5. (선택) 완전 무인화 — 크롬 자동 실행 예약
사람이 크롬을 켜는 것조차 생략하려면, PC가 켜져 있는 상태에서 OS가 크롬을 자동 실행하게 합니다.

**Windows (작업 스케줄러)**
1. 시작 메뉴 → `작업 스케줄러` 실행
2. 오른쪽 **기본 작업 만들기** → 이름: `RACK 크롬 자동실행`
3. 트리거: **매일**, 시간: 예약 시각 5분 전 (예: 07:55)
4. 동작: **프로그램 시작** → 프로그램:
   `C:\Program Files\Google\Chrome\Application\chrome.exe`
5. 마침 → 완료

**macOS**: `시스템 설정 → 로그인 항목`에 Chrome 추가(로그인 시 자동 실행) 또는 캘린더 자동화 사용.

## 6. 저장 방식 (v1.5.0에서 바뀐 점)
- 저장 키는 `<호스트>.<브랜드슬러그>` — 야간 자동 수집과 **같은 규칙**입니다.
  예) `freepeople.com.freepeople` / `freepeople.com.fpmovement`
  → 한 도메인에 브랜드가 둘이어도 절대 섞이지 않습니다.
- 브랜드의 카테고리를 **전부 돈 뒤 한 번에** 저장하며, 매번 통째로 교체합니다.
  (어제의 품절 상품이 계속 쌓이지 않음)
- 카테고리당 최대 150개, 브랜드당 최대 750개까지 저장합니다.
  미로 앱은 그중 카테고리별 100개를 보여줍니다.
- 예전 버전이 호스트 이름으로 저장해 둔 옛 데이터는 첫 실행 때 자동으로 지워집니다.

## 7. 팀원 안내 (설정 불필요)
- 미로 보드 → Market Lens 앱 → **Market Research** 에서 브랜드 검색
- 확장 담당 브랜드도 그날 수집본이 리스트로 표시됩니다
- 수집 시각 이후 상품이 갱신되므로, 하루 한 번 아침 수집이면 충분합니다

## 문제 확인
- 팝업의 **지난 실행** 줄에서 브랜드 성공/실패 개수 확인
- 진행 로그에 브랜드별로 `✅ <브랜드> · N개 저장` 또는 실패 사유가 남습니다
- 실패가 많은 날: **지금 전체 실행**으로 재시도
- 특정 브랜드가 계속 실패하면 관리자(개발 담당)에게 사이트 주소와 함께 알려주세요
